선택하는 기능이에요

클래식, 데일리, 여유 모드는 계정 없이 사용할 수 있으며 진행과 설정은 이 브라우저에 저장됩니다. 친구 대결은 닉네임과 기록 표시 동의를 입력해 별도로 시작합니다. 동의하지 않아도 혼자 플레이는 이용할 수 있습니다. 카카오 로그인·친구 목록·공유 API는 사용하지 않습니다.

혼자 플레이와 공유

공유 링크는 별도 새 판을 열고 기존 진행은 덮어쓰지 않습니다. 공유판은 최근 8개까지 이 브라우저에 별도로 저장하며 같은 탭을 새로고침하면 이어갈 수 있습니다. 공유 링크에는 보드·진행 상태·계정 정보가 포함되지 않습니다. 기록을 공유하면 사용자가 선택한 상대에게 점수와 게임 링크가 전달됩니다. 브라우저의 사이트 데이터를 지우면 일반 진행과 공유판도 삭제됩니다.

이 브라우저에 연결되는 계정

무작위 계정 번호와 보안 쿠키로 같은 브라우저를 구분합니다. 닉네임은 본인인증이 아니며 다른 사람과 중복될 수 있습니다. 다른 기기·다른 브라우저에서는 별도 계정이 만들어집니다. 쿠키 삭제, 기기 연결 해제, 90일 미접속 후에는 기존 계정을 복구할 수 없습니다. 닉네임만으로 다른 기기의 계정에 로그인할 수 있는 기능은 제공하지 않습니다.

사용하는 정보와 목적

  • 무작위 계정 번호, 직접 정한 닉네임, 생성·최근 이용 시각: 기기 계정 구분과 미사용 데이터 정리.
  • 친구방 이름·참가 정보, 점수·최고 타일·이동 수·등록 날짜: 친구방 운영과 일간·주간 순위.
  • 이동 방향 기록: 제출 시 점수를 재계산하는 데 일시적으로 처리하며 원본 배열을 DB에 저장하지 않습니다.
  • 세션 토큰의 해시, IP 기반 요청 제한 키의 해시: 연결 유지와 과도한 요청 방지. DB에 원본 세션 토큰이나 원본 IP를 저장하지 않습니다.

이메일, 전화번호, 연락처, 카카오 식별번호, 프로필 사진은 요청하지 않습니다. 광고·행동 분석 도구를 넣지 않았습니다.

친구에게 보이는 범위

등록한 기록과 닉네임은 해당 방에 참가한 계정만 볼 수 있습니다. 초대 링크를 가진 사람은 방 이름·인원을 확인하고 참가할 수 있으며, 링크는 다시 전달될 수 있습니다. 믿는 친구에게만 보내세요. 전체 공개 순위표는 없습니다. 공유는 초대 링크 복사 또는 기기의 공유 메뉴를 사용하며, 카톡의 보낼 상대 선택과 전송은 사용자가 직접 합니다.

보관 및 삭제

  • 점수는 최근 90일분, 대결 시도 정보는 최대 2일분을 정기적으로 정리합니다.
  • 보안 쿠키·서버 세션은 90일 후 만료되며 친구방을 다시 방문하면 갱신됩니다. 요청 제한 정보는 최대 하루의 유효기간 후 정리됩니다.
  • 마지막 이용 후 90일이 지난 계정과 참가 정보는 매일 실행되는 정리 작업에서 삭제합니다. 만료 직후부터 다음 정리까지 차이가 있을 수 있습니다.
  • '이 방 나가기'는 해당 방의 내 기록을, '내 게임 데이터 삭제'는 내 계정·참가 정보·세션·서버 기록과 이 기기의 진행 중인 친구 대결을 삭제합니다. 다른 참가자가 있는 방은 다른 사람에게 관리 권한을 넘기며 다른 사람의 기록은 지우지 않습니다.
  • '기기 연결 해제'만 선택하면 서버의 기존 기록은 보관 기간까지 남지만 그 계정으로 복귀할 수 없습니다. 전체 삭제가 목적이라면 먼저 '내 게임 데이터 삭제'를 사용하세요.

운영 DB에서 삭제한 데이터도 Cloudflare의 복구용 백업에는 무료 플랜 기준 최대 7일간 남을 수 있습니다. Cloudflare 백업 안내. 혼자 플레이 기록은 별도로 브라우저의 사이트 데이터 삭제 기능을 이용하세요.

제공 업체 및 국외 처리

호스팅·DB 제공 업체는 Cloudflare, Inc.입니다. 친구방 기능을 선택하면 위 정보가 HTTPS로 Cloudflare Workers·D1에 전송되어 계정 유지와 순위 제공을 위해 처리됩니다. D1은 APAC 지역으로 생성했으며 APAC은 한국 내 저장을 보장하지 않습니다. Workers 및 네트워크 보안 처리는 글로벌 네트워크에서 이루어질 수 있습니다. Cloudflare는 네트워크 서비스 제공 과정에서 접속 IP 등 연결 정보를 자체 정책에 따라 처리할 수 있습니다. 국외 서버 처리를 원하지 않으면 친구방 계정을 만들지 말고 혼자 플레이를 이용해 주세요.
