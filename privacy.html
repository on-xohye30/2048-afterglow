혼자 플레이와 친구 대결은 달라요

클래식, 데일리, 여유 모드는 로그인 없이 사용할 수 있고 진행과 설정은 이 브라우저에 저장됩니다. 친구 대결은 카카오 로그인을 선택한 뒤 서버에 연결하는 기능입니다. 서버가 연결되지 않은 정적 버전에서는 친구 대결을 제공하지 않습니다.

서버에서 사용하는 정보

  • 카카오 앱별 회원번호: 같은 사용자를 구분하고 로그인 계정을 연결하기 위해 사용합니다. 친구에게 공개하지 않습니다.
  • 닉네임: 카카오계정 닉네임을 처음 사용하고, 게임 안에서 수정할 수 있습니다.
  • 친구방 이름, 참가 정보, 점수, 최고 타일, 이동 수, 등록 시각: 방 관리와 일간·주간 순위를 위해 사용합니다.
  • 이동 방향 기록: 등록 시 점수를 서버에서 재계산하는 데 일시적으로 처리하며, 원본 이동 배열을 데이터베이스에 저장하지 않습니다.
  • 보안 세션과 해시된 요청 제한 정보: 로그인 유지와 악용 방지에 사용합니다. 서비스 코드에서 카카오 액세스 토큰을 로그인 처리 이후 보관하지 않습니다.

이메일, 전화번호, 연락처, 프로필 사진과 카카오톡 친구 목록은 이 기능에서 요청하지 않습니다. 광고나 행동 분석 도구를 사용하지 않습니다.

누가 내 기록을 볼 수 있나요?

게임 닉네임과 등록한 점수는 내가 참가한 친구방의 로그인된 참가자에게만 보입니다. 초대 링크를 가진 사람은 방 이름과 인원 수를 확인하고 직접 참가할 수 있으니 신뢰하는 친구에게만 링크를 보내세요. 초대 링크를 받은 사람이 다른 사람에게 전달할 수도 있습니다. 카카오톡으로 누구에게 보낼지는 사용자가 직접 선택하며 자동 메시지를 보내지 않습니다.

보관과 삭제

  • 친구방 기록은 최근 90일분을 보관하며 정기 삭제 작업으로 정리합니다.
  • 진행 시도는 최대 2일, 로그인 세션은 최대 14일, 로그인 확인 상태는 10분 후 만료됩니다. 만료 데이터는 정기 작업으로 정리합니다.
  • 게임 계정, 닉네임과 방 참가 정보는 삭제를 요청할 때까지 보관합니다.
  • 친구방에서 나가면 해당 방의 내 점수와 대결 정보가 삭제됩니다.
  • 친구방 화면의 '내 게임 데이터 삭제'로 계정, 세션과 서버의 내 기록을 삭제할 수 있습니다. 다른 친구의 기록이 있는 방은 다른 참가자에게 관리 권한을 넘깁니다.

서버 데이터 삭제와 별개로 카카오계정의 연결된 서비스 설정에서 이 서비스의 연결을 해제할 수 있습니다. 이 브라우저의 혼자 플레이 기록은 브라우저의 사이트 데이터 삭제 기능으로 지울 수 있습니다.

서비스 제공 업체와 저장 환경

카카오는 사용자가 선택한 로그인 및 카카오톡 공유를 처리합니다. 친구 대결 서버는 운영자가 연결한 Cloudflare Workers와 D1 환경에서 실행·저장되며, 처리 위치는 해당 운영 환경과 업체 정책에 따릅니다. 친구 기능 공개 전 운영자는 실제 처리 지역, 적용되는 위탁·국외 이전 고지 및 운영 연락처를 확인하여 이 안내에 반영해야 합니다.
