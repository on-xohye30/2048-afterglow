# 2048_plusplus

> 친구와도 즐기는 독립 제작 2048 게임입니다. 닉네임으로 친구방에 참가하고 카톡에 초대 링크를 보내 일간·주간 기록을 경쟁합니다. **카카오 API나 로그인은 사용하지 않습니다.** 친구방은 Cloudflare Workers + D1에서 실행하며, 기존 GitHub Pages 싱글 플레이도 유지합니다.

플레이: **https://2048-afterglow.on-xohye30.workers.dev/**

친구방 운영 및 배포: [FRIENDS_SETUP.md](./FRIENDS_SETUP.md)

한 수 더, 2048. 로그인 없이 가볍게 즐기는 한국어 숫자 퍼즐입니다.

**플레이:** https://on-xohye30.github.io/2048-plusplus/

## 포크 없이 새로 만든 게임

2048의 익숙한 규칙에서 영감을 받아 게임 엔진, UI, 애니메이션과 스타일을 새로 작성했습니다. 다른 2048 저장소를 포크하거나 소스를 복사하지 않았습니다. 게임 규칙의 원작은 Gabriele Cirulli의 2048이며, 참고 플레이 화면은 https://mgarciaisaia.github.io/2048/ 입니다. 원작자와 제휴한 공식 서비스가 아닙니다.

## 플레이 모드

- **클래식:** 4×4, 한 판당 되돌리기 3회. 합쳐진 숫자가 점수에 더해지는 원래 규칙.
- **오늘의 도전:** 한국 시간(Asia/Seoul) 날짜별 고정 시드. 같은 날짜, 같은 이동이면 동일한 타일이 나옵니다. 되돌리기 없이 도전하고 같은 퍼즐을 다시 시작할 수 있습니다. 온라인 랭킹은 없습니다.
- **여유 모드:** 5×5, 되돌리기 횟수 무제한. 최근 100개의 이동까지 보관합니다.

## 작은 재미

- 방향키 / WASD / 화면 방향 버튼 / 모바일 스와이프
- U로 되돌리기, R로 새 게임 (진행 중에는 확인 창)
- 2048 달성 뒤에도 계속 플레이
- 연속 합치기 표시와 다음 타일 목표 (보너스 점수 없이 클래식 채점)
- 모드별 진행, 최고 점수, 난수 상태 자동 저장
- 라이트 / 다크 모드, 선택형 효과음, 텍스트 기록 공유
- 키보드 접근성, 스크린 리더용 상태 알림, 모션 줄이기 지원

## 실행 및 테스트

Node.js 22.13 이상. 게임 및 테스트는 외부 패키지 설치 없이 실행합니다. 친구 서버 배포에는 Wrangler와 본인 Cloudflare 계정 연결이 필요합니다.

```sh
npm start
# http://127.0.0.1:4173/
npm test
```

또는 정적 웹 서버에서 이 폴더를 제공하면 됩니다. JavaScript ES 모듈을 쓰므로 index.html을 파일로 직접 열지 말고 HTTP 서버로 실행하세요.

## 구조

- engine.js: DOM과 독립된 순수 게임 로직, 시드 난수
- engine.test.mjs: Node 내장 테스트, 합치기/점수/전이/불변성/재현성 검증
- app.js: 입력, 애니메이션, 모드와 저장 상태
- index.html, styles.css: 접근성과 반응형 UI
- server.mjs: 로컬 개발 전용 정적 서버

GitHub Pages는 main 브랜치 루트의 정적 파일을 배포합니다. 기존 싱글 플레이에는 빌드 도구나 서버, API 키가 필요하지 않습니다. 친구 기능은 같은 origin의 서버와 DB가 필요하므로 GitHub Pages만으로 활성화되지 않습니다.

## 개인정보와 저장

기존 싱글 플레이에는 외부 분석, 광고, 쿠키, 회원 가입, 외부 CDN 요청이 없습니다. 선택형 친구 기능은 기기 기반 닉네임 계정, 보안 쿠키 및 Cloudflare 저장을 사용합니다. 기기 변경·쿠키 삭제 후 기존 계정은 복구할 수 없습니다. 처리 범위는 [개인정보 안내](./privacy.html)를 참고하세요. 진행 상황과 설정은 이 브라우저의 localStorage에 저장됩니다. 캐시/사이트 데이터 삭제 시 기록도 사라지며 기기 간 동기화되지 않습니다. 데일리 진행 기록은 최근 7일분을 보관합니다. 모드별 저장 영역을 분리하고, 같은 모드의 다른 탭에서 발생한 변경을 받아 최신 진행을 이어갑니다. 공유 링크는 0점의 별도 새 판을 엽니다. 기존 모드별 진행은 그대로 보관하며, 공유판은 최근 8개를 별도로 저장합니다. 같은 탭의 새로고침은 그 공유판을 이어가고, 링크를 새로 열면 다시 새 판을 시작합니다. 모드 선택의 “이전 판 이어하기”로 원래 저장판에 돌아갈 수 있습니다. 데일리는 링크의 날짜와 같은 퍼즐로 시작합니다. 공유는 버튼을 눌렀을 때 텍스트와 링크를 클립보드에 복사하며 자동으로 전송하지 않습니다.

## 2.1 UI 리디자인

사용자 제공 디자인을 바탕으로 크림·테라코타 색상, 한국어 세리프 제목, 모드 선택 패널, 새 게임 확인, 공유 카드와 친구방 화면을 적용했습니다. 화면의 숫자는 실제 게임 상태와 서버 순위에서 읽습니다. 글꼴은 로컬 호스팅하며 `assets/fonts/`에 라이선스를 포함합니다.

표시 이름은 `2048_plusplus`입니다. 기존 브라우저 저장, 일일 퍼즐, 세션, 초대 링크를 보존하기 위해 내부 저장 키·쿠키 이름·기존 Worker 주소와 D1 이름은 유지합니다. GitHub 저장소 주소는 실제 이름인 `2048-plusplus`를 사용합니다.

## 2.2 공유 진입과 간결한 조작

- 공개 공유 링크는 `play=1`을 사용하며 보드·점수·계정·친구방 식별자를 담지 않습니다. 이전 `mode`/`date` 형식도 새 판으로 엽니다.
- `shared-game.js`가 공유판 저장을 일반 모드 저장과 분리합니다. 친구방 초대와 인증 계정 동작은 바꾸지 않습니다.
- 메인은 점수와 보드 중심입니다. 설정·도움말·저장 안내는 설정 메뉴에서 열 수 있습니다.
- 넓은 PC 화면은 방향 버튼을 보드 오른쪽에 둡니다. 모바일은 직접 스와이프가 기본이며, 설정에서 버튼을 켜면 보드 위에 표시합니다.
